GitHub bağlantısı

Yayınla düğmesi menüyü ve fotoğrafları tek bir kayıt olarak GitHub deponuza gönderir. Vercel değişikliği görür ve siteyi yaklaşık yarım dakikada günceller.

Anahtarı şöyle oluşturun:
  1. GitHub, Settings, Developer settings, Fine grained tokens, Generate new token
  2. Yalnızca bu depoyu seçin
  3. Repository permissions bölümünde Contents için Read and write verin
  4. Oluşan anahtarı buraya yapıştırın
Anahtar yalnızca bu tarayıcıda saklanır. Ortak bir cihazda işiniz bitince "Anahtarı sil" deyin.
